# Ponte Digital

Plataforma de Apoio Social | Distrito de Lisboa, Portugal

Agrega, georreferencia e disponibiliza informação sobre recursos de apoio
social no distrito de Lisboa — alimentação, saúde, emprego, apoio social
e educação.

## Stack

- Backend: FastAPI (Python 3.12)
- Base de dados: PostgreSQL 16 + PostGIS 3.4
- Frontend: HTML/CSS/JS estático + Leaflet.js
- Deploy: Docker Compose + Nginx + Hetzner Cloud

## Desenvolvimento

cd /srv/ponte-digital
docker compose up -d
